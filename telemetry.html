Telemetry Design

A telemetry system to monitor the hydrogen powertrain system of the UofT Supermileage Urban Concept car

Design

As part of UofT Supermileage's Urban Concept team, I helped to design and implement a telemetry system to monitor the hydrogen powertrain system of the car. The telemetry system was designed using an Arduino microcontroller to read data from various sensors placed throughout the car and transmit the data wirelessly to a remote computer. The remote computer would then log the data for further analysis.
